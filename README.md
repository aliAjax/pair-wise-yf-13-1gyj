# hxyfront-62001 船舶轮机值班台

源提示词编号：1

纯前端船舶轮机值班记录系统（React + Vite + TypeScript），数据仅保存在浏览器 localStorage，刷新后保留。

## 功能

- **机舱看板**：当前班次、值班时长、本班记录数、未处理严重/普通异常统计，各设备最新读数与状态灯
- **参数录入**：主机（转速/滑油压力/冷却水温/燃油消耗/排烟温度）、1~2 号发电机（电压/频率/电流/功率）、1~3 号泵组（出口压力/流量/电流）
- **历史查询**：按设备筛选全部参数记录，并显示每条记录触发的异常
- **异常时间线**：全部班次异常按时间排列，支持级别/状态筛选与在线处理登记
- **交接班**：生成本班交接摘要（与看板、时间线同源同步），记录交班/接班人，保留过往班次摘要

## 异常判定规则

严重异常（处理前拦截交接，永久保留且级别不变）：

- 主机运转中滑油压力 < 0.10 MPa
- 主机运转中冷却水温 > 95 ℃
- 主机停转（转速为 0）仍消耗燃油

普通异常（未处理可结转到下一班）：主机排烟温度 > 450 ℃、发电机电压超出 380V±5%、频率超出 49.5~50.5Hz、泵组出口压力 < 0.20 MPa、泵组电流 > 45A。

## 交接拦截

当前班存在未处理严重异常时，「确认交接」被禁用并列出拦截项；在时间线中登记处理人后即可交接。未处理的普通异常自动结转到下一班并标注来源班次。
